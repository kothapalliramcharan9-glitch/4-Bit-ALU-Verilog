4-Bit ALU Using Verilog HDL

Project Description

This project implements a 4-bit Arithmetic Logic Unit (ALU) using Verilog HDL in Xilinx Vivado.

Tools Used

- Xilinx Vivado
- Verilog HDL

Project Contents

- ALU Design Code
- Testbench Code
- Simulation Waveform

Operations

- Addition
- Subtraction
- AND
- OR
- XOR

Objective

To design and verify a 4-bit ALU using Verilog HDL and understand digital logic design.
